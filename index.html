      使用说明

      1. 准备分层模型

      膝关节模型必须 按部件分开命名，否则无法单独控制显隐、透明度与热力高亮。建议在 Blender 中拆分后导出：

      部件建议对象名（包含关键词即可）
      股骨Femur / femur
      胫骨Tibia / tibia
      胫骨平台Tibia_Plateau
      髌骨Patella / patella
      内侧半月板Meniscus_Medial
      外侧半月板Meniscus_Lateral
      交叉 / 侧副韧带ACL / PCL / MCL / LCL

      2. 放置文件

      导出为 GLB（推荐，含动画）后放到 assets/models/knee.glb，刷新页面即自动加载；若文件不存在或解析失败，系统会自动回退到内置解析模型，页面不会报错空白。

      3. 其他注意事项

      • 面数建议控制在 15 万三角面以内，导出时勾选 Draco 压缩可显著减小体积（本项目未启用 Draco，如需启用请自行加载解码器）。
      • 模型的「膝关节屈伸中心」最好放在世界原点附近，相机会自动按包围盒取景。
      • 可用 index.html?model=assets/models/你的模型.glb 临时指定其他模型路径。

      1. 动作库结构（15 类 × 正误 = 30 段）

      全部动作集中在 js/motions.js 这一个数据源里，按四个主题分组：

      • 日常步态：平地行走、上楼梯、下楼梯、坐站转移、上坡。
      • 训练力量：深蹲、弓步蹲、硬拉、骑行。
      • 冲击落地：跑步、纵跳落地、单腿跳、下坡跑。
      • 球类变向：侧切变向、踢球。

      每类动作都有「标准 / 错误」两段，例如 anim_squat_correct 与 anim_squat_valgus。 每段包含：膝关节轨道（屈伸 / 外翻 / 胫骨旋转 / 股骨内收）、应力-时间曲线、全身姿态曲线、力学锚点与科普文案。

      2. 新增或修改动作

      1. 在 motions.js 的 M 对象里仿照现有条目新增一个模式，填好 knee / stress / profile / body / info 五部分。
      2. 把它加入 MODES 数组并归入某个 GROUPS 分组，UI 目录、力学读数、科普文案、全身小窗会自动接入，无需改动其它文件。
      3. 膝轨道单位为「度」，全身姿态曲线单位为「弧度」；正确姿态的应力曲线整体压在 0.2 以下（阈值 0.25 全程不显红）。

      3. 替换 GLB 自带骨骼动画

      若 knee.glb 自带 Blender 烘好的 clip，系统按名称模糊匹配优先使用； 动作库中 GLB 未提供的其余动作，会用相同的关节节点名（FemurPivot / TibiaPivot / PatellaPivot / KneeRoot）自动合成补齐，保证 30 段全部可播。 在 Blender 中把 Action 重命名为对应 key、勾选 Fake User、导出时勾选 Animation 即可。

      4. 全身人体主画面与膝关节特写

      画布主体渲染的是真实人体解剖模型（écorché：浅层肌肉 + 骨骼，来自 human-atlas / BodyParts3D）， 由 assets/models/human.json + human.bin 提供网格，js/bodyFigure.js 用 17 根骨骼做线性混合蒙皮； 可用鼠标拖拽旋转、滚轮缩放。它读取 motions.js 的 bodyOf() 姿态曲线，与膝关节动画共用归一化进度同步摆姿； 资产加载期间回退程序化玻璃人，fetch 被禁（如 file:// 双击打开）时自动改用内嵌副本 human-data.js，两者皆失败才保留玻璃人，永不白屏。 人体右膝处的橙色环随应力升高变红，蓝色粗线是“髋→膝→踝”负重力线，灰色竖线是重力参考，膝内扣时膝中心明显偏离参考线。

      画布右上角的小窗是正在仿真的膝关节特写（knee.glb 分层模型）：分屏对比时左右各一，分别对应标准 / 错误姿态； 热力着色、图层显隐、部件点击拾取均作用于此窗。面板「显示膝关节特写」开关可将其隐藏。

      点击小窗（部件以外的空白处）即可把两个视图对调：膝关节特写成为主画面、人体缩到右上角小窗，再点小窗即切回人体主视角。 人体与膝关节特写都可以拖拽旋转 / 滚轮缩放，两个视角按同一世界方位实时联动（拖哪边，另一边即刻跟随）。

      5. 力学证据读数

      画布左下角与右侧面板的接触力（×BW）、内外侧间室分配、力线偏移、Q角、KAM 由 js/biomech.js 计算， 锚点同样取自 motions.js 的 profiles()。这些值依据公开文献量级做教学映射，不是有限元或个体化测量结果。

      1. 创建仓库

      git init
git add .
git commit -m "feat: knee simulation site"
git branch -M main
git remote add origin https://github.com/你的用户名/你的仓库名.git
git push -u origin main

      2. 开启 Pages

      1. 进入仓库 Settings → Pages。
      2. Source 选择 Deploy from a branch，分支选 main，目录选 / (root)，保存。
      3. 等待 1–2 分钟，访问 https://你的用户名.github.io/你的仓库名/。

      3. 必须注意

      • 所有资源使用 相对路径（本项目已全部使用相对路径），不要写 /js/main.js 这类绝对路径。
      • 文件名区分大小写，knee.glb 与 Knee.glb 在 Pages 上会被视为不同文件。
      • 仓库若开启私有，Pages 需付费方案；毕业设计用公开仓库即可。
      • 仓库根目录已带 .nojekyll；Three.js 依赖随仓库本地提供，不依赖外网 CDN。
      • 本地预览建议用 python -m http.server 或 VS Code Live Server；新版 Chrome / Edge 直接双击 index.html 通常也能加载，个别浏览器限制本地文件时会自动回退内置模型。
